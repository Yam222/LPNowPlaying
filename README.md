# LP Now Playing 2

브라우저에서 **YouTube**나 **YouTube Music**으로 음악을 틀면, 지금 나오는 곡을 **돌아가는 LP판** 모양으로 화면 구석에 띄워 주는 프로그램이에요.
게임이나 영상 위에도 항상 떠 있고, LP판을 클릭하거나 돌려서 음악을 바로 조작할 수 있어요.

- 곡 제목 · 아티스트 · 링크 · 앨범아트를 LP판과 함께 표시
- 앨범아트 색에 맞춰 카드 색이 자동으로 바뀜
- LP판 클릭 = 재생/정지, LP판 돌리기 = 재생 위치 이동, ⏮ ⏭ 버튼 = 이전/다음 곡
- 방송용 OBS 화면도 지원

```
YouTube / YouTube Music 탭 ─▶ 크롬 확장 프로그램 ─▶ LPNowPlaying2.exe ─┬─▶ 화면 오버레이 (내 모니터, 항상 맨 위)
                                                                        └─▶ OBS 브라우저 소스 (방송 화면, 선택)
```

---

## 준비물

- **Windows 10 또는 11**
- **Chrome 또는 Microsoft Edge** (확장 프로그램을 설치할 브라우저 하나)
- **Microsoft Edge WebView2 런타임** (Windows 11과 대부분의 Windows 10에는 이미 설치돼 있어요. 없으면 프로그램이 설치 페이지를 열어 줘요)

## 설치 (3단계, 처음 한 번만)

### 1. 프로그램 실행
`LPNowPlaying2.exe`를 원하는 폴더에 두고 실행하세요. 설치 과정 없이 바로 실행돼요.

- **"Windows의 PC 보호"** 창이 뜨면 **추가 정보 → 실행**을 누르세요.
  개인이 만든 프로그램이라 코드 서명이 없어서 뜨는 경고예요.

### 2. 크롬 확장 프로그램 설치
1. 프로그램 설정 창 맨 아래 **[확장 프로그램 폴더 꺼내기]**를 누르세요. 폴더가 열리고, 폴더 경로가 자동으로 복사돼요.
2. 크롬 주소창에 `chrome://extensions`를 입력하세요. (Edge는 `edge://extensions`)
3. 오른쪽 위 **개발자 모드**를 켜세요.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고, 1번에서 열린 폴더를 선택하세요.
5. 확장 프로그램 목록에 **LP Now Playing 2**가 생기면 완료예요.

> 꺼낸 폴더(`%LOCALAPPDATA%\LPNowPlaying2\chrome-extension`)는 지우지 마세요. 지우면 확장 프로그램이 동작하지 않아요.

### 3. 시작
1. 설정 창에서 **[시작]**을 누르세요.
2. YouTube나 YouTube Music에서 음악을 트세요.
3. 화면 오른쪽 아래에 LP판이 나타나면 성공이에요.

설정 창 **음악 소스** 칸에 **"● 확장 프로그램 연결됨"**이 보이면 정상적으로 연결된 거예요.

> 다음부터 프로그램을 켜자마자 시작하고 싶으면 **표시 · 실행 → 실행하면 바로 시작**을 켜세요.

## 사용법

### 화면에 보이는 것

- **카드 (왼쪽)**: NOW PLAYING · 재생 중인 곳(YOUTUBE / YOUTUBE MUSIC), 곡 제목(길면 자동으로 흘러가요), 아티스트, 링크
- **⏮ ⏭ 버튼**: 카드 오른쪽 아래
- **LP판 (오른쪽)**: 가운데 앨범아트, 판 둘레를 따라 도는 제목 글자, 바깥쪽 진행바(원)

재생 중인 곡이 없거나 광고가 나오는 동안에는 자동으로 사라져요. 곡이 바뀌면 사라졌다가 새 곡으로 다시 나타나요.

### 마우스로 조작하기

| 동작 | 결과 |
|---|---|
| LP판 **클릭** (판 어디든) | 재생 / 정지. 판 가운데에 ▶ / ❚❚ 아이콘이 잠깐 떠요 |
| LP판 **잡고 돌리기** (판 어디든) | **시계방향 = 앞으로, 반대 방향 = 뒤로**. 돌리는 동안 판과 진행바, `2:31 / 4:05 (+0:24)` 같은 시간 표시가 미리 움직이고, **손을 떼면 그 위치로 이동**해요 |
| LP판 위에서 **마우스 휠** | 위로 = 5초 앞으로, 아래로 = 5초 뒤로 |
| **⏮ 버튼** | 3초 넘게 재생했으면 곡 처음으로, 3초 안이면 이전 곡 |
| **⏭ 버튼** | 다음 곡 |

- **LP판과 ⏮ ⏭ 버튼 위에서만** 마우스가 동작해요. 카드의 나머지 부분은 클릭이 그대로 통과해서, 아래에 있는 게임이나 프로그램을 평소처럼 조작할 수 있어요.
- 오버레이를 클릭해도 게임이나 다른 창의 포커스를 뺏지 않아요.
- **LP판 한 바퀴 = 30초**예요. 노래 모음처럼 긴 영상은 **영상 길이 ÷ 20**이 한 바퀴예요. 어떤 영상이든 20바퀴 돌리면 처음부터 끝까지 가요. (예: 1시간 영상은 한 바퀴에 3분)
- 손이 살짝 흔들리는 정도는 클릭으로 인식해요. 확실히 돌려야 이동으로 인식해요.
- 영상이 끝나기 1초 전까지만 이동해요. 실수로 다음 곡으로 넘어가지 않게 하려는 거예요.
- 광고 중이거나 라이브 방송처럼 길이가 없는 영상은 이동할 수 없어요.

**이전 곡 동작 자세히**
- YouTube Music, YouTube 재생목록: 재생목록의 이전 곡으로 가요.
- 재생목록이 없는 YouTube 영상: **이 탭에서 전에 봤던 영상**으로 가요. 이 탭에서 처음 본 영상이면 처음으로 되감기만 해서, 유튜브 홈 화면으로 나가지 않아요.

### 단축키 (게임 중에도 동작)

| 단축키 | 동작 |
|---|---|
| `Ctrl + Alt + ←` | 이전 곡 |
| `Ctrl + Alt + →` | 다음 곡 |
| `Ctrl + Alt + L` | 오버레이 숨기기 / 다시 보이기 |

- 이전/다음 곡 단축키는 프로그램이 **[시작]** 상태일 때만 동작해요.
- 마우스 커서가 게임 화면 가운데에 고정되는 게임(FPS 등)에서는 마우스로 오버레이를 조작할 수 없으니 단축키를 쓰세요.
- 다른 프로그램이 같은 단축키를 이미 쓰고 있으면 설정 창에 ⚠ 안내가 떠요.
  인텔 그래픽 PC는 `Ctrl + Alt + 방향키`가 **화면 회전** 단축키로 잡혀 있을 수 있어요. 그럴 때는 인텔 그래픽 설정에서 그 단축키를 끈 다음, 프로그램을 [중지] → [시작] 하세요.

## 설정 창 안내

### 화면 오버레이

| 설정 | 설명 | 기본값 |
|---|---|---|
| **다른 프로그램 위에 항상 표시** | 오버레이 켜기/끄기 | 켜짐 |
| **숨기기 / 보이기** 버튼 | `Ctrl + Alt + L`과 같아요 | |
| **모니터** | 표시할 모니터 | 주 모니터 |
| **위치 · 크기** | 네 모서리 중 위치, 크기 75~200% | 오른쪽 아래, 100% |
| **여백** | 화면 가장자리에서 떨어진 거리 | 가로 24px, 세로 56px (작업 표시줄 위) |
| **불투명도** | 오버레이 전체의 진하기 | 100% |
| **계속 맨 위로 올리기** | 다른 "항상 위" 창이 덮어도 다시 맨 위로 올라와요 | 켜짐 |
| **녹화·방송 화면에서 숨기기** | 내 모니터에만 보이고, 화면 녹화나 OBS 디스플레이 캡처에는 찍히지 않아요 | 꺼짐 |

오버레이 칸 아래의 **"마지막 조작"** 줄에는 방금 한 조작이 어떻게 처리됐는지 표시돼요. (문제 해결에 유용해요)

### 표시 · 실행 (화면 오버레이와 OBS 공통)

| 설정 | 설명 |
|---|---|
| **배경 투명도** | 0% = 기본 카드, 100% = 카드 배경 없이 글자와 LP판만. 배경이 옅을수록 글자 그림자가 진해져서 밝은 화면에서도 잘 보여요 |
| **앨범 색 강조** | 0% = 색 없이 은은한 흰색, 100% = 앨범 색 그대로(기본), 150% = 더 진하고 선명하게 |
| **링크 표시** | `youtu.be/…`, `music.youtube.com/…` 줄 켜기/끄기 |
| **LP판 회전 속도** | 아주 느리게(14초에 한 바퀴) / 느리게(8초, 기본) / 보통(4초) / 실제 LP(1.8초) |
| **실행하면 바로 시작** | 프로그램을 켜자마자 [시작] 상태로 |

### 여러 탭에서 재생 중일 때
- **재생 중인 탭 우선** (기본): 소리가 나는 탭을 먼저 표시하고, 없으면 가장 왼쪽 탭을 표시해요.
- **항상 첫 번째 탭**: 가장 먼저 연 창의 가장 왼쪽 YouTube / YouTube Music 탭을 표시해요.

조작(클릭, 버튼, 단축키)은 항상 **지금 오버레이에 표시 중인 탭**에 적용돼요.

## 인식 방식

- **YouTube Music**: 곡 제목, 아티스트, 앨범, 앨범아트를 그대로 사용해요.
- **YouTube**: 영상 시청 화면(`youtube.com/watch`)과 미니플레이어만 인식해요. 홈 화면에서 마우스를 올렸을 때 나오는 미리보기는 무시해요.
  영상 제목에서 곡 제목과 아티스트를 뽑아서 보여 줘요.

  | 영상 제목 | 표시 |
  |---|---|
  | `[MV] IU(아이유) _ Love wins all` | **Love wins all** / IU(아이유) |
  | `BTS (방탄소년단) 'Dynamite' Official MV` | **Dynamite** / BTS (방탄소년단) |
  | `Official髭男dism - Pretender［Official Video］` | **Pretender** / Official髭男dism |
  | `Artist - Title (Official Video)` | **Title** / Artist |

  이렇게 정리할 수 없는 제목은 영상 제목과 채널 이름을 그대로 보여 줘요.

## OBS로 방송할 때

### 화면 오버레이가 방송에 보일까?
화면 오버레이는 게임과 따로 떠 있는 창이에요. 그래서 OBS에서 화면을 어떤 방식으로 잡는지에 따라 달라요.

| OBS 소스 | 방송에 LP가 보이나 |
|---|---|
| **게임 캡처** (예: 마인크래프트를 게임 캡처로 잡음) | ❌ 안 보여요. 게임 화면만 가져와요 |
| **윈도우 캡처** (게임 창만 잡음) | ❌ 안 보여요 |
| **디스플레이(모니터) 캡처** | ✅ 보여요. "녹화·방송 화면에서 숨기기"를 켜면 안 보여요 |

게임 캡처나 윈도우 캡처로 방송하면서 시청자에게도 LP를 보여 주려면, 아래 **OBS 브라우저 소스**를 추가하세요.
디스플레이 캡처와 브라우저 소스를 같이 쓰면 LP가 두 번 찍혀요. 그럴 때는 "녹화·방송 화면에서 숨기기"를 켜세요.

### OBS 브라우저 소스 추가하기
1. 설정 창 **OBS 브라우저 소스**를 켜세요.
2. 주소 옆 **[복사]**를 누르세요. 주소는 `http://127.0.0.1:47800/overlay?target=obs` 같은 형태예요.
3. OBS에서 **소스 + → 브라우저**를 고르고, URL에 붙여 넣으세요.
4. 너비/높이는 **640 × 260** 정도로 설정하고, OBS 화면에서 원하는 위치로 옮기세요. 크기를 125% 이상으로 키웠다면 영역도 그만큼 넉넉하게 잡아 주세요.
5. **[미리보기]**를 누르면 OBS에 어떻게 보일지 브라우저에서 먼저 확인할 수 있어요.

- 설정 창에서 위치·크기를 바꾸면 주소가 바뀌니, OBS에 주소를 다시 붙여 넣으세요.
- 프로그램을 새 버전으로 바꾸면 OBS 화면은 자동으로 새로고침돼요.

## 전체화면 게임에서

- **테두리 없는 창 모드 / 전체 창 모드**에서는 항상 보여요.
- Windows 10/11에서는 "전체화면"으로 설정해도 실제로는 테두리 없는 창처럼 동작하는 게임이 대부분이라 그대로 보여요.
- 게임이 **독점 전체화면(Exclusive Fullscreen)**으로 화면을 직접 차지하면, Windows가 그 위에 다른 창을 그리지 않아서 오버레이가 안 보일 수 있어요.
  그럴 때는 게임 그래픽 설정에서 **"테두리 없는 창 모드"**(또는 "전체 창 모드")로 바꿔 주세요.

## ⚠ 안티치트(뱅가드 등) 관련 주의

**결론: 위험은 낮은 편이지만 0은 아니에요.** 사용은 본인 판단으로 해 주세요.

### 위험이 낮은 이유
이 프로그램은 치트가 쓰는 핵심 기술을 쓰지 않아요.
- 게임 프로그램 안에 끼어들지 않아요 (DLL 주입, 후킹 없음).
- 게임 메모리를 읽지 않아요.
- 드라이버를 설치하지 않아요.
- 게임 파일이나 게임 입력을 건드리지 않아요.

게임 바깥에서 화면 위에 투명한 창을 하나 띄울 뿐이에요. 조준선 표시 프로그램(Crosshair X 등)이나 화면 위젯과 같은 방식이에요.

### 0이 아닌 이유
- **라이엇(뱅가드)은 어떤 프로그램이 밴 대상인지 공식 목록을 공개하지 않아요.** 그래서 확실히 안전하다고 말할 수 있는 사람이 없어요.
- 같은 방식의 오버레이 프로그램이 **일부 게임에서 밴 대상이 된 사례**가 보고돼 있어요. 게임사마다 기준이 달라요.
- "항상 맨 위에 뜨는, 클릭이 통과하는 투명 창"은 일부 치트(외부 ESP)가 화면을 그릴 때 쓰는 방식과 생김새가 같아요. 이 프로그램은 게임 정보를 전혀 읽지 않지만, 탐지 시스템이 창의 생김새만 보고 의심할 가능성은 있어요.
- 일부 안티치트는 플레이 중인 화면을 캡처해 가는 것으로 알려져 있어요. 그 화면에 LP 오버레이도 그대로 보여요.

### 걱정된다면
- **발로란트 같은 엄격한 게임**에서는 플레이 전에 `Ctrl + Alt + L`로 숨기거나, 설정 창에서 **[중지]**하는 게 가장 안전해요.
- **방송용으로만 쓴다면** 화면 오버레이를 끄고 **OBS 브라우저 소스만** 쓰세요. 게임 화면 위에 아무것도 그리지 않아요.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| LP판이 안 나타나요 | ① 설정 창에서 [시작]을 눌렀는지 ② 음악 소스 칸에 "확장 프로그램 연결됨"이 보이는지 ③ `Ctrl + Alt + L`로 숨긴 상태는 아닌지 확인하세요 |
| "확장 프로그램 연결 안 됨" | 확장 프로그램이 설치돼 있는지, YouTube 탭이 열려 있는지 확인하세요. 탭을 새로고침(F5)해 보세요 |
| "⚠ 예전 확장 프로그램이에요" | [확장 프로그램 폴더 꺼내기] → `chrome://extensions`에서 LP Now Playing 2의 **새로고침(↻)** |
| 클릭·버튼·단축키가 안 먹어요 | 설정 창 **"마지막 조작"** 줄을 보세요.<br>· "✓ 실행됨" → 정상이에요<br>· "확장 프로그램이 명령을 가져가지 않았어요" → 확장 프로그램 **새로고침(↻)**<br>· "YouTube 탭에서 실행되지 않았어요" → YouTube 탭 **F5** 새로고침<br>· 아무것도 안 바뀌어요 → 클릭이 프로그램에 닿지 않은 거예요. 오버레이가 다른 창 뒤에 있지 않은지 확인하세요 |
| LP판 위에서 휠이 안 먹어요 | Windows 설정 → Bluetooth 및 장치 → 마우스 → **"비활성 창 위로 마우스를 가져갈 때 스크롤"**을 켜 주세요 (기본값은 켜짐) |
| "포트 47800을 열 수 없어요" | 이 프로그램이 이미 켜져 있거나, 예전 LP Now Playing(1.x)이 켜져 있는지 확인하세요 |
| 게임에서만 오버레이가 안 보여요 | 게임을 테두리 없는 창 모드로 바꾸세요 ("전체화면 게임에서" 참고) |
| 한자·일본어 일부가 네모로 보여요 | 맑은 고딕에 없는 글자예요. 한글, 영문, 일본어 가나는 대부분 표시돼요 |
| 크롬과 엣지를 같이 쓰면 표시가 왔다 갔다 해요 | 확장 프로그램은 브라우저 하나에만 설치해서 쓰세요 |

## 개인정보와 보안

- 모든 통신은 **내 PC 안(`127.0.0.1`)**에서만 일어나요. 외부 서버로 보내는 데이터는 없어요.
- 앨범아트 이미지만 구글/유튜브 이미지 서버에서 받아 와요. 색 추출도 프로그램이 직접 해요.
- 일반 웹사이트가 몰래 이 프로그램에 접속해서 재생을 조작하거나, 듣고 있는 곡을 읽어 가지 못하게 막혀 있어요. 확장 프로그램과 OBS 화면만 접속할 수 있어요.

## 자원 사용 (측정값)

| 항목 | 사용량 |
|---|---|
| 오버레이 그리기 | LP판이 도는 동안 CPU 한 코어의 약 3%. 일시정지하거나 숨기면 거의 0 |
| 프로그램 메모리 | 본체 약 15MB + 글꼴 약 16MB + 설정 창 80~150MB |
| 확장 프로그램 | 프로그램이 꺼져 있으면 10초에 한 번만 확인 |
| 인터넷 | 곡마다 앨범아트 한 장 (1시간에 약 2~5MB) |

설정 창을 최소화하면 설정 창은 화면을 그리지 않아요.

## 파일 위치

| 항목 | 위치 |
|---|---|
| 설정 파일 | `%APPDATA%\LPNowPlaying2\settings.json` |
| 꺼낸 확장 프로그램 | `%LOCALAPPDATA%\LPNowPlaying2\chrome-extension` |
| 설정 창 캐시 | `%LOCALAPPDATA%\LPNowPlaying2\WebView2` |

## 삭제하기

1. 설정 창을 닫아 프로그램을 끄세요.
2. `chrome://extensions`에서 LP Now Playing 2를 **삭제**하세요.
3. `LPNowPlaying2.exe`와 아래 두 폴더를 지우세요.
   - `%APPDATA%\LPNowPlaying2`
   - `%LOCALAPPDATA%\LPNowPlaying2`

레지스트리나 시스템 파일은 건드리지 않아서 이것만 지우면 깨끗하게 삭제돼요.

## 개발자용: exe 다시 빌드하기

```
cd source/app
go mod tidy
set GOOS=windows& set GOARCH=amd64& go build -trimpath -ldflags "-H windowsgui -s -w" -o LPNowPlaying2.exe .
```

Go 1.24 이상이 필요해요. 아이콘과 매니페스트는 `rsrc_windows_amd64.syso`에 들어 있어요 (원본은 `winres/` 폴더).
